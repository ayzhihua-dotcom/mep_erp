# 《S1 交付物：主数据初始化规范》草案（V0.1）

- 编制依据：SRS V1.0（主数据与组织结构要求）、《ERP 模块功能清单与字段字典 V0.2》（MDM / PRJ / INV / LPO 域）、《S1 交付物：组织角色与权限矩阵》（V0.1）、《S1 交付物：三语基础配置方案》（V0.1，D-11）。
- 编制日期：2026-10-28
- 状态：草稿（待业务方评审确认；具体命名/清单待业务方提供后填充）

## 一、定位与范围

- 目标：给出 S2 开发起步前，Dev/Test 环境必须建立的**主数据初始化清单、录入模板与校验规则**，避免开发期因数据不齐反复返工。
- 范围：公司、仓库、项目/WBS 骨架、物料组、计量单位、材料、供应商、用户与角色、系统参数。不含业务交易数据（订单/装运等，属 S2+ 验收数据）。

## 三、必填字段与校验规则（初始化模板基线）

### 3.1 公司（D-1）

| 字段 | 规则 |
| --- | --- |
| company_name / code | 唯一；与法定主体名称一致（巴西主体同步葡语注册名） |
| default_currency | C1=CNY；C2=BRL |
| country / timezone | 中国主体=Asia/Shanghai；巴西主体=America/Sao_Paulo |

### 3.2 仓库（D-2）

| 字段/规则 | 内容 |
| --- | --- |
| company 归属 | 必填且唯一公司（INV-001：仓库必须归属公司） |
| parent_warehouse | 层级三级：站点级 → 功能仓 → 区域/库位仓 |
| 仓库类型 | 标注类型：发运仓/暂存仓/合格品仓/待检仓/隔离仓/冻结仓（承载 INV-003/011 状态化库存） |
| warehouse_name | 中文命名 + 简码；启用 is_rejecting_warehouse 等系统语义仓时须与质检流程匹配 |

### 3.3 项目与 WBS（D-3）

| 字段/规则 | 内容 |
| --- | --- |
| Project | 编码唯一；补齐 V0.2 PRJ-001 字段：合同编号、合同金额、预算金额、预算币种 |
| WBS | 编码唯一、父级非空校验、防父级循环（PRJ-002）；初始化至少覆盖"楼栋→施工区域→专业包"三级示例 |

### 3.4 材料与单位（D-4 ~ D-6）

| 字段/规则 | 内容 |
| --- | --- |
| item_code | 内部编码唯一且稳定；编码规则建议"大类-专业-流水"（待业务确认 M-01） |
| 三语名称 | 中文必填（= item_name）；`custom_item_name_pt` / `custom_item_name_en` 可后补（MDM-002 / D-11） |
| 规格字段 | 材质、型号、品牌、标准等（MDM-003）必选其一填写规则按物料组区分 |
| stock_uom | 库存类材料必填；UOM 转换关系随数据一并初始化 |
| 进口属性 | NCM（巴西 NCM 码）、原产国（MDM-006/IMP-003）：进口类材料初始化时预填或标注"待归类审核"状态 |
| 停用标志 | 初始化期不建停用数据；上线后停用走 MDM-009 流程 |

### 3.5 供应商（D-7）

| 字段/规则 | 内容 |
| --- | --- |
| 分组 | 中国供应商组 / 巴西本地供应商组（支撑 PRC/BRA 角色数据范围与 LPO-001） |
| CNPJ | 巴西主体必填（LPO-001）；中国主体填写统一社会信用代码作为对应字段 |
| 联系人/供应范围 | 至少一条联系人 + 供应物料组 |

### 3.6 用户与系统参数（D-8 ~ D-9）

- 示例用户按《权限矩阵》角色命名（如 dev.prc / dev.bra / dev.whs…），便于 Test 环境权限验证与 IC-01~IC-08 演练。
- System Settings：默认语言 zh、会话/登录策略待 P-02 确认项先记为默认值，版本核验时复核。
- 多币种：CNY、BRL（必设）、USD（可选）；汇率维护策略（每日手动/对接来源）待 D 决策清单确认（M-02）。

## 四、初始化执行方式

1. 公司/仓库/物料组/UOM：ERPNext 标准界面或 Data Import 模板完成（Data Import 即 ALR-005 口径：先预览校验、失败行可下载）。
2. 材料批量初始化：如首批 > 100 条，走 MDM-007 批量导入通道（预览、去重、分批、错误报告）。
3. Custom Fields / DocType 本身（Design BOM 等）不属本初始化范围，属定制应用代码交付（S1 ①）。
4. 每类数据初始化完成后在 Dev 做快照备份（对应《环境方案》第六节 Dev 备份策略）。

## 五、验收要点

1. 初始化清单 D-1~D-9 在 Dev 环境全部建立并可查询。
2. 必填字段/唯一性/层级校验规则生效（尝试违规录入被拒）。
3. 示例用户可按角色登录并看到对应数据范围（承接 S1 ② 验收第 2 条）。
4. 材料三语完整率报表可运行（初始允许葡/英为空，中文 100%）。
