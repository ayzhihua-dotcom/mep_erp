## 一、任务定位

| 项 | 内容 |
| --- | --- |
| 覆盖功能 | INV-002 收货登记、INV-003 质量验收、INV-004 正式入库 |

| 前置依赖 | 仓库层级（待检/隔离/合格仓）、INV 检验模板配置 |

## 二、功能设计

### 2.1 收货登记（INV-002）

| 字段/规则 | 说明 |
| --- | --- |
| receipt_source | 收货来源：进口案件（清关提货后）/ 本地 PO / 项目间调拨到达 |
| supplier / posting_date / receipt_location | 标准；项目/WBS/包装/批次关联字段 |
| 部分收货 | 允许；对 PO 行累计收货量 (记录使用) |
| 超收控制 | 超收 = 超过 PO 行余量：默认阻断；授权例外（高权限 + 原因 + 审计） |

### 2.2 质量验收（INV-003）

| 规则 | 说明 |
| --- | --- |
| 强制检验 | 需检 Item（quality inspection 模板配置）：未完成检验前不入合格仓 → 入待检/隔离仓 |
| 检验结果 | 合格 → 转合格仓入库；不合格 → 隔离仓 + 退货/换货流程（INV-006 衔接）或让步接收（审批） |
| 检验指标 | 模板自定义参数（ Exterior 外观/尺寸/材质符合性…，模板字典待业务） |

### 2.3 正式入库（INV-004）

- 来源单据（PO / Import Case / 调拨）、来源仓 → 目标仓、批次、操作人、项目归属；
- 库存变动全部走库存交易（禁止改余额）；入库后并绑定 PR/检验附件归档。

## 四、验收用例

| 用例 | 通过标准 |
| --- | --- |
| UC-W01 | 超收被拒（或授权例外后可超收并留痕） |
| UC-W02 | 需检 Item 未检验期间不能进合格仓 |
| UC-W03 | 部分收货余量统计正确 |
| UC-W04 | 不合格处理路径完整（隔离/让步/退货三选记录） |
| UC-W05 | 入库后审计可回查 PR/检验单 |
