## 一、任务定位

| 项 | 内容 |
| --- | --- |
| 覆盖功能 | INV-005 领料出库、INV-006 退料、INV-008 项目间调拨；激活 CST-006 领料成本归集 |
| 实现形态 | 标准 Stock Entry（Material Issue / Transfer）+ 定制审批与校验 |

## 二、功能设计

### 2.1 领料出库（INV-005）

| 字段/规则 | 说明 |
| --- | --- |
| 领料单输入 | 项目、WBS/施工区域、领料人、领料日期、用途、批准人、关联需求（MR/BOM 行） |
| 超领控制 | 领用量 > 已批准申请量：授权例外（高权限）+ 记录 + ALR 类事件占位 |
| 跨项目领用 | 禁止默认；须授权 + 留痕 |
| 成本归属 | 出库行带 custom_project_cost / WBS → 计入项目实际成本（CST-006 激活；计价取 Stock Ledger 值） |

### 2.2 退料（INV-006）

- 必须关联原领料单（或收货单，如进口收货退货）或经批准原因；
- 质量状态记录；原交易保留不删；退料后可用库存回归、项目成本冲减（负向归集）。

### 2.3 项目间调拨（INV-008）

| 字段/规则 | 说明 |
| --- | --- |
| 调入/立项 | 保留原项目与接收项目（成本转移：原项目减、接收项目加，同一时点） |
| 审批 | 双方项目经理会签（默认，可配置） |
| 在途 | 复用仓库调拨在途机制（TP-INV-003 承接 Transfer 细节） |
