## 二、四视图指标设计（口径全部承接既有计算）

| 视图 | 核心卡片/图表 | 数据来源 |
| --- | --- | --- |
| 供应链 | 在途批次数与金额、ETA 未来 7/30 天到达、异常未结数、按时交付率 | Shipment / Milestone / Exception / PUR-008 |
| 库存 | 现场总仓+分仓可用/冻结/待检数量与金额、资金占用趋势 | Bin / Stock Ledger / INV 冻结 |
| 成本 | 各项目预算 vs 承诺 vs 实际 vs EAC、超预算项目清单、进口费用摊入趋势 | CST-001/002/005/007 |
| 项目 | 各项目需求缺口 TOP 列表、预警未结 TOP、项目状态分布 | PRJ-006 快照 / Alert Event / Project |

## 三、口径一致性原则

1. 驾驶舱任何指标必须引用与业务模块**同一**计算服务或报表（禁止驾驶舱另算一套数）；
2. 与 ALR 统计口径一致（如"未结预警数"直接取 Alert Event status 统计）；
3. 每张卡片标注计算口径与刷新时间（D-11 中文优先）。
