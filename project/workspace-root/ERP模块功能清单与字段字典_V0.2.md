- 编制日期：2026-10-28
- 状态：V0.2 修订草稿（功能章节已起草：PRJ/PUR/LOG-IMP/CST/INV-WH/LPO/ALR-BI/MDM/UI；待定稿）

## 一、V0.1 → V0.2 修订摘要

1. **编号口径统一**：V0.2 正式采用 SRS V1.0 原始功能编号（PRJ-001 ~ PRJ-007 / MDM-xxx / PUR-xxx / LOG-xxx / IMP-xxx / LPO-xxx / INV-xxx / CST-xxx / ALR-xxx / BI-xxx），不随意改号。
2. **设计编号映射**：V0.1 设计编号（PRJ/MAT/DEM/PUR/SHP/IMP/LOC/WH/CST/ALT）作为暂定映射；PRJ 域中 PRJ-001~006 编号同序对应，PRJ-007 为 V0.2 新增条目。
3. **覆盖缺口修补**：PRJ-007 项目关闭由“未覆盖”转为正式条目；PRJ-001 补充合同/预算字段；PRJ-004/PRJ-005 语义错位通过编号口径统一修正。
4. **V0.2 尚未定稿**：D-01~D-10 等业务决策、ERPNext 目标版本核验、数据库与流程设计待后续修订。

## 十、界面设计原则与界面功能点（UI/UX）

### 设计原则

1. **简单易用**：后台默认安全；主操作一键完成；减少录入字段，默认自动带出；关键操作有明确反馈。
2. **现代科技化**：统一设计系统；信息架构清晰；驾驶舱可视化；移动端轻量操作模式。
3. **PC + 移动端**：PC 端标准业务表单；移动端扫码/列表领料、到货登记、清关状态、预警通知。

### 界面功能点

1. **PC 端**：采购订单、进口案件、成本、盘点、预警等标准表单；后台安全默认。
2. **移动端**：扫码/列表领料、到货登记、清关状态查看、预警通知接收（数据范围与权限一致）。
3. **BI 驾驶舱**：供应链、库存、成本、项目视图（承接 BI-001；指标口径与 CST/ALR 一致）。
4. **多语言**：界面、按钮、模板、通知、格式（SRS 九、九.1）。

### 界面验收要点

- 移动端权限与数据范围一致；
- 驾驶舱指标与成本/预警统计口径一致；
- 三语界面输出可验证。
