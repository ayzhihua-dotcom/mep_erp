# 《核心业务流程与状态转换规范》草稿（V0.1）

- 编制依据：SRS V1.0《中国—巴西工业机电工程 ERP 系统建设方案》（第 5、6 节核心流程与状态控制）；《ERP 模块功能清单与字段字典 V0.2》（本项目草案）；覆盖对照与修订工作清单。
- 编制日期：2026-10-28
- 状态：草稿（V1.0 / 修订中）

## 一、通用状态与转换原则

1. 状态采用 ERPNext 原生状态与自定义状态组合；关键业务状态由流程引擎 / 单据提交行为控制，不允许普通用户随意改文本。
2. 已提交关键单据不可直接覆盖关键业务数据；更正通过取消/修订、差异记录或冲销流程实现，保留审计轨迹（V0.1 编制规则）。
3. 状态变更须留痕：计划时间、实际时间、更新时间、信息来源、操作者、审批人。
4. 预计到货日期变更须留痕（LOG-008；V1.0 §5.1/§5.2）。

## 二、端到端主链路状态机

### 2.1 设计材料清单 → 需求 → 采购链

- Design BOM（PRJ-003）：草稿 → 已提交 → 审核 → 锁定；审核后不可覆盖，设计变更生成新版本或变更记录（PRJ-004/PRJ-005）。
- 需求汇总（PUR-002 / DEM-001）：需求总量 = 设计数量 × (1 + 损耗率)；净采购缺口 = max(0, 需求总量 − 可用库存 − 已确认在途 + 其他占用纠正）——口径待业务方确认（V0.1 已提示互斥集合）。
- Material Request（PUR-001）：草稿 → 提交 →（询价/比价）→（审批）→ 采购订单；订单关闭时校验剩余未交数量、退货、费用、异常（PUR-009）。

### 2.2 采购订单 → 装运 → 清关 → 收货 → 入库 → 领料 → 成本链

- Purchase Order（PUR-007）：草稿 → 已提交 → 已批准 → 生效 → 部分到货 → 已关闭；已批准订单改单须重新审批。
- Shipment（SHP/LOG）：装运批次支持多订单合并、订单行分批（SHP-001/002）；运输节点记录订舱/发运/到港/提货（LOG-005 新增）；到货预测更新须留痕（LOG-008）。
- Import Case（IMP）：案件状态节点：创建 → 单证清单 → 申报 → 查验 → 补资料 → 放行 → 提货 → 归档；清关放行、物流提货、仓库验收为三个不同事件（IMP-008）。
- Purchase Receipt（INV-002/WH-002）：收货检验 → 正式入库（INV-004）；库存变动必须走库存交易单据。
- Stock Entry（INV-005/WH-005）：领料批准 → 出库；退料（INV-006/WH-006）须关联原交易或审批。
- Cost：Import Cost（IMP-005/006）→ Landed Cost Voucher（CST-004）→ 分摊 → 项目成本（CST-003/006）→ 预算偏差（CST-007）→ 预警（ALR）。

### 2.3 状态转换总表（关键单据）

| 单据 | 状态流 | 关键转换条件 |
| --- | --- | --- |
| Material Request | 草稿 → 已提交 → 已批准 → 订单 | 审批节点/阈值；订单关闭校验 |
| Purchase Order | 草稿 → 已提交 → 已批准 → 生效 → 部分到货 → 关闭 | 部分到货累计收货/拒收；超收例外 |
| Shipment | 创建 → 发运 → 部分到港/提货 → 完成/异常 | 多批次/分批规则；异常升级 |
| Import Case | 创建 → 单证 → 申报 → 查验 → 补资料 → 放行 → 提货 → 归档 | 单证齐备才推进；三事件区分 |
| Stock Entry（出/入/调） | 申请/创建 → 批准 → 执行 → 完成/差异 | 调拨接收差异审批；冻结 |
| Project Close | 执行中 → 检查 → 关闭/退回 | 关闭检查：未交货订单、未处理预留、未结清费用、剩余材料 |

## 三、异常与中断处理

1. 运输异常（LOG-007）：状态转暂停/异常；触发 ALR 预警；影响到货预测。
2. 清关异常（IMP-007）：状态转异常；单证缺失触发预警；补资料后恢复。
3. 缺口/超预算：采购建议/成本偏差 → ALR 预警分派处理。

## 四、验收要点（流程层）

1. 主链路全流程状态可追溯。
2. 部分到货/分批/多项目/多订单场景可用关联记录回溯。
3. 成本分摊与预算偏差有可核对计算。
