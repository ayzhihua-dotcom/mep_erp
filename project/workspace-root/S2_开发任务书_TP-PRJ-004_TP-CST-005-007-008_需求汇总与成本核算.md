## 二、块 A：需求汇总（PRJ-006 / PUR-002）

### 2.1 计算口径（承接 V0.2 PRJ-006 条目）

```
需求总量 = Σ(设计数量 × (1 + 批准损耗率))       [Detail BOM 行]
已领用量 = Σ领料出库(项目+Item)                  [轿法: Stock Entry MI 行]
已分配量 = Σ已批准 MR 未完全转单量               [MR 行]
可用库存 = 项目现场仓可用数量               [Bin/Stock Ledger]
确认在途 = Σ装运已发运未到货 + 已批准 PO 未发运(采购承诺口径, 二选一可配置)
净采购缺口 = max(0, 需求总量 − 已领用 − 已分配宏大名额 − 可用库存 − 确认在途 + 其他占用纠正)
```

> 全部口径在计算服务中为**可注释参数**（损耗率默认值、"其他占用纠正"开关）；D-v1 决策冻结后默认值落锅。

### 2.2 输出与留痕

| 要求 | 实现 |
| --- | --- |
| 快照单据 Demand Summary Snapshot：项目/Item/WBS 行 + 各口径数 + 计算时点 + 版本 + 明细来源链接 | 重算生成新快照，不覆盖历史（V0.2"保存计算时点/版本"） |
| 已批准申请/承诺不受重算覆盖 | 快照为只读分析对象，不写回 MR/PO |

## 三、块 B：库存成本围栏（CST-005）

| 项 | 方案 |
| --- | --- |
| 计价政策 | Item Group / Company 层配置 valuation_method（Moving Average / FIFO，ERPNext 支持，以 L-02 版本核验确认可用性）；政策一经启用不得随意切换（记录审计） |
| 台账 | Stock Ledger + Stock Entry 依据交易单据（禁止直改余额，INV-004 衔接） |
| 项目维度成本 | 领料出库行携带 custom_project_cost（TP-CST-A-04 字段位）累计进项目实际成本 |

## 四、块 C：预算偏差（CST-007）

| 列 | 定义 |
| --- | --- |
| 预算 | 活动版 Material Budget |
| 承诺 | CST-002 承诺台账（同日美丽时点） |
| 实际 | 已确认费用（PI/进口费用分摊到项目）+ 领料成本（S3 激活前留 0 说明） |
| 完工预测（EAC） | 预算 ×（1 + 当前偏差系数）或 简化人工输入（首版取简化，D-v2） |
| 偏差 | 预算 − 承诺 − 实际；< 0 触发 ALR-0004 风险记录（S5 激活） |

## 五、块 D：调整审计（CST-008）

- 审计事件类型：成本调整 / 汇率覆盖 / 分摊调整 / 预算版本变更（承接 ALR-006 清单）；
- 实现：统一 Cost Audit Log（操作人、原值、新值、原因、对象）+ track_changes；管理员规则限定可写方用在 SYS/FIN + A。
