## 二、DocType 设计

### 2.1 Material Budget（CST-001）

| 字段 | 规则 |
| --- | --- |
| project / discipline（专业）/ wbs_link / budget_division type | 项目、专业系统、工作包、（可选）材料维度预算 |
| budget_amount / budget_currency | 预算金额与币种（建议=BRL 主口径，以合同币种设置） |
| version / approval_status / effective_date | 预算版本（调增/调减走版本 + 审批） |
| line 级 | 按专业或 WBS 细分行；同 project+X 唯一（同项目、同维度对象仅一个活动版本） |

### 2.2 采购承诺统计（CST-002）

| 字段袋袋 | 规则 |
| --- | --- |
| 承诺口径 | 已批准且仍有效的 PO 金额，按 Project Allocation 归集到项目 / WBS |
| 时点快照 | 承诺明细快照（承诺时点、PO、行、金额）；PO 改单后快照按最新有效状态重建 |
| 输出 | Commitment Ledger（承诺台账）：项目维度承诺累计、按专业/WBS 分例；供 BI/预警 |

### 2.3 领料成本接口（CST-006，S3 激活）

- 领料出库（Stock Entry）行携带项目/WBS 成本归属字段（本任务在 DocType 上加字段位）；
- 实际归集逻辑在 S3 领料任务书承接；本任务只做字段与取数结算框架（`is_发运类` 判定预留）。

## 三、预算校验（PUR-006 衔接）

| 校验 | 规则 |
| --- | --- |
| 位置 | PO 提交与审批节点执行：Sum(该项目有效承诺 + 本单金额) vs 该项目该专业活动版预算金额 |
| 超限动作 | 计入 `custom_budget_check`：`over_limit_amount`（超限金额）+ 触发分流审批（TP-PUR-006-02 承接）|
| 项目无预算版预算 | 配置决定：阻断 / 提示允许 / 强制先建预算（D-y14） |

## 五、验收用例

| 用例 | 通过标准 |
| --- | --- |
| UC-B01 | 预算调增未审批则不生效于校验 |
| UC-B02 | 承诺台账 = Σ 有效 PO × 分配量/金额，与手工抽取一致 |
| UC-B03 | 超限 PO 进入追加审批并标记超限金额 |
| UC-B04 | PO 取消后承诺台账扣减 |
| UC-B05 | 同项目同专业仅一个活动预算版本，旧版本只读 |
