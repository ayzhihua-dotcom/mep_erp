# 《S5 交付物：预警与驾驶舱联动联调说明》草案（V0.1）

- 编制依据：TP-ALRBI-001/002、《成本核算与预算偏差》系任务书、UI/UX 章节（口径一致性验收要点）。
- 编制日期：2026-10-28
- 状态：草稿

## 一、联调目标

- 验证"业务模块 → 计算/规则 → 预警 → 驾驶舱 → 钻取回业务单据"全链一致性；
- 关闭"口径分叉"风险：任何数字在驾驶舱、预警、业务报表中必须同源。

## 二、联调场景清单（端到端 8 例）

| 场景 | 链路验证点 |
| --- | --- |
| L-01 缺料预警闭环 | BOM 变更 → 需求快照重算 → 净缺口 > 0 → Alert Event → 工作台 → 处理 → 驾驶舱缺口榜下降 |
| L-02 支付承诺违约 | 承诺日 > 需求日 何时触发 → ALR-002 类 → PRC 达收 → 结案原因留痕 |
| L-03 超预算 | 三笔 PO 累计超限 → 超限预警 + PO 审批分流记录一致 |
| L-04 ETA 延误 | 节点推迟 → ETA 新版本 → 预警 → 库存 PVC 需求影响说明（口径） |
| L-05 单证缺失暂停 | 单证缺失 → 清关挡智 → 关闭条件（补齐或豁免） |
| L-06 冻结库存不入可用 | 冻结 → MR 计算排除 → 库存报表可用减少一致 |
| L-07 进口分摊入成本 | LCV 分摊 → 项目实际费用 → 成本驾驶舱与偏差报表一致 |
| L-08 三语通知 | 同一预警给中文用户与葡语用户不同模板（D-11） |

## 三、一致性问题处理规则

- 发现口径分叉：先归因（参数不同 / 时点不同 / 计算逻辑不同）→ 修正规则主档 → 回归 L-01~08；
- 禁止在驾驶舱层临时"补差" 数值。

## 四、验收标准

1. 8 例场景全部通过并留存演示记录（截图 + 数据快照）。
2. 《指标口径说明》发布，每卡片/每关联预警一句口径。
3. S5 验收汇总可引用本文件作为一致性证据。
