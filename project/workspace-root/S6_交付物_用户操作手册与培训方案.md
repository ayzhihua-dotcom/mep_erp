- 编制依据：SRS §九培训 / UI-UX 章节（D-11 口径）、S2~S5 任务书全部业务流程、SRS I/O 验收。
- 编制日期：2026-10-28
- 状态：草稿

## 一、用户操作手册结构（中文主版）

| 章 | 内容 |
| --- | --- |
| 1 | 系统总览与登录（个人设置：语言切换、密码、数据范围说明） |
| 2 | 材料/主数据维护（录入、三语名称、停用） |
| 3 | 设计与需求（Design BOM 编制、变更发起与处理） |
| 4 | 采购（申请、询价、比价、审批、订单、交期、关闭） |
| 5 | 装运与进口（装运登记、单证、案件进度、 anomalous 异常处理） |
| 6 | 库存（收货质检入库、领料退料、调拨盘点、冻结）与移动端操作专项 |
| 7 | 成本（预算维护、分摊、偏差查看） |
| 8 | 预警（工作台处理、豁免）与驾驶舱 |
| 9 | 常见问题与故障求助（含数据更正禁令提醒：禁止直改台账） |

- 每章配：操作步骤（截图）+ 视频链接位 + 常见错误提示；
- 手册版本状态：中文版 P0 首发双语贡版推进（葡语版以 D-11 分批策略）。

## 二、培训方案

| 对象 | 形式 | 重点 |
| --- | --- | --- |
| 全员 | 集中 1 天 + 手册自学 | 登录、主页、预警、禁令与求助 |
| 工程人员 | 半天实操 | BOM、变更 |
| 采购 PRB/BRA | 半天 chacol 实操 | 询价、比价、订单、审批链；PRC/BRA 隔离演示 |
| 物流/清关 | 半天 | 装运、进口案件、异常 |
| 仓储人员 | 半天 + 移动端实操 | 收货质检、领料扫码、盘点 |
| 财务/PM/管理层 | 半天 | 预算、分摊、驾驶舱 |
| SYS | 私训（框架/维护/备份/升级窗口、审计） | 版本/环境/权限管理 |

- 每次培训后：问卷收集 + 高频问题回馈手册（修订记录）。

## 三、验收要点

1. 手册 P0 流程完整覆盖 106 用例的操作主干。
2. 各角色至少完成一次实操演练并通过问卷 >= 阈值（建议 80%）。
3. 葡语版关键章节（登录、领料、预警）首发可读。
