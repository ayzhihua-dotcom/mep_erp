## 二、功能设计

### 2.1 仓库调拨（INV-007）

| 环节 | 规则 |
| --- | --- |
| 三段式 | 调出（在途入中转仓/在途仓）→ 中转 → 接收确认 |
| 差异处理 | 接收量 ≠ 发送量：差异记录 + 审批；残留差异走盘点/报废说明 |
| 异常 | 在途中时间超阈值 → ALR 类事件占位（长时间未到货） |

### 2.2 盘点（INV-009）

| 字段 | 规则 |
| --- | --- |
| 盘点批次/计划日期/范围 | Stock Reconciliation 承载账面 vs 实盘 |
| 差异 | 实盘 − 账面；原因必填；重大差异（比例阈值待定）→ 二级审批（PM + FIN） |
| 提交独立性沿革 | 盘点提交人不可为该差异的二级审批人（IC-03） |

### 2.3 批次追溯（INV-010）

- 以 Item + 批次号/序列号为入口，回溯：装运行 → 进口案件 → 收货检验 → 库存交易历史；
- 输出追溯树报表（一问到底：该批材料从哪个 PO/哪船舶来 → 进过哪些仓 → 被领用于哪些 WBS）。

### 2.4 库存冻结（INV-011）

| 规则 |
| --- |
| 冻结维度：仓库/批次/Specific stock 记录；冻结原因（异常/HB/质检/争议）+ 冻结人 |
| 冻结后该范围不可出库/不可净计入可用库存（MR 计算 D-v1 口径联动） |
| 解冻须 PM + FIN 双权（高权限）+ 理由留痕（IC-06） |

### 2.5 库存报表（INV-012，P1）

- 报表：CPU。按仓库/库位/项目/材料查看账面、可用、冻结、待检数量及金额；
- 导出（Excel），预留 ALR-005 uni 导入报表通道（需时）。
