# 《外部接口规范（V0.1）》

- 编制依据：SRS V1.0（系统集成相关）、S4-BR2（NF 对接）、S4-L2（ETA 数据来源）、S5-A2（通知通道）、L-05（接口规范属于 S0 带出项）
- 编制日期：2026-10-28
- 状态：草稿（接口实现范围依赖 O-01 部署形态与 S4/E4 决策；本期口径 = **登记式优先，自动化对接为可选增强**）

## 一、接口总原则

1. **登记优先**：所有外部数据首先以内人工录入/附件上传方式进入系统（各 DocType 已承载），接口是增强不是前置；
2. **幂等与留痕**：任何接口写入必须带来源批次号，重复推送不重复入账（对齐 ALR-005 幂等原则）；
3. **回退路径**：接口故障时切回人工模式（每接口给降级方案）；
4. **安全**：出站 API 不暴露 ERPNext 后端凭证；用独立集成用户+最小权限。

## 三、关键接口详设

### 3.1 IF-01 清关节点回传（最重要）

| 项 | 规则 |
| --- | --- |
| 触发 | 代理在节点发生后 ≤ 24h 推送（邮件档：代理发结构化邮件模板） |
| 数据映射 | 事件类型 → Milestone.milestone_type；附件 → evidence_attachment；案件号 → import_case_no |
| 幂等 | (import_case_no, milestone_type, actual_date) 已存在则忽略 |
| 审计 | 来源 = auto_import_agent / 操作者记录 |

### 3.2 IF-02 物流事件

| 项 | 规则 |
| --- | --- |
| 键 | (shipment_no, node_type)；ETA 更新生成新版本行（LOG-008 留痕口径） |
| 频率 | 每日批量拉取（在途批次） |

### 3.3 IF-04 NF-e 登记方案（首发）

- Import/local PI 时字段 custom_nf_e + XML 附件；报表按月核对；
- 对接 SEFAZ 自动获取 = E4-BR2 决策后二期。

## 四、验收要点

1. 每接口有降级路径文档化；
2. 幂等测试：同源重复推送不入账；
3. 集成用户权限最小化核查。
