## 二、框架设计

### 2.1 Alert Event（统一对象）

| 字段 | 规则 |
| --- | --- |
| alert_type | 缺料 / 交期违约 / 供应商逾期 / 单证缺失 / 放行未提货 / 超预算 / 超领 / 盘点差异 / 冻结/在途超时 / ETA 延误（承接 S2~S4 全部占位） |
| ref_doctype / ref_docname | 关联业务对象 |
| project / item / metric_value（净缺口/超限金额/逾期天数） | 主维度数据、严重度 |
| assignee / due_date | 责任人 / 处理期限（按规则映射角色） |
| status（待处理/处理中/已关闭） / close_reason | 处理闭环留痕（可豁免走 IC-05 授权） |
| computed_at / rule_version | 计算时点与规则版本（可追溯重算） |

### 2.2 去重与合并（避免轰炸）

- 同类型 + 同对象 + 未关闭 → 更新数值而非新建；同项目同类多对象可合并为一条汇总预警（明细子行）。

### 2.3 调度

- 调度：ERPNext 定时；需求密集点建议每 15 分钟计算（按规则不同节拍）；
- 通知：Email / 系统通知；语言偏好按 D-11（语言偏好模板）。

## 三、规则清单（首批 1 类 + 时效 4 类 + 成本 1 类）

| 规则 | 条件 | 责任映射 |
| --- | --- | --- |
| 缺料（ALR-001） | 需求已批准未采购 + 净缺口 > 0（TP-PRJ-004 计算） | PM/ENG |
| 承诺交期违约 | Promise > 需求日期（PUR-008） | PRC |
| 供应商逾期 | 承诺已过 N 天无收货（N 待定） | PRC |
| 单证缺失/停更 | Document 缺失或 N 天未动（LOG-006/IMP-002） | CUS |
| 已放行未提货 | 放行事件 + N 小时未提货（IMP-008） | LOG |
| 超预算 / 偏差劣化 | 偏差 < 0 或 EAC 劣化（CST-007） | PM/FIN |
| …（各场景由 S2~S4 占位事件激活清单统一给出） | | |
