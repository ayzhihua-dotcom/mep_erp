1. 字段级数据字典完整版（含 `custom_` 前缀约定与字段级校验规则）；
2. 外部接口规范 IF-01~11（每接口含降级路径与幂等规则）；
3. BPMN 正式版（单池五泳道 + 可导入 XML，L-03 关闭）；
4. 移动端详细设计（PWA 首选、四场景首发、扫码领料线框级定义）；
5. 字段级保密与审计配置清单（10 角色 F/V/H 矩阵 + 六类审计事件 + Cost Audit Log）。

### 3.4 外部 AI 接口（本轮新增能力）

- **MCP 标准接口**承载 12 个只读工具（项目/库存/缺口/PO/装运/清关/费用/偏差/预警/材料检索/供应商绩效/whoami），外部 AI 软件与智能体可即插即用；
- 安全硬规则：独立服务账号、数据范围与权限矩阵同源、**字段保密服务端过滤**（非界面隐藏）、每次调用入 MCP Audit Log、限流与密钥轮换；
- 非 AI 软件数据互通走 IF-11（Frappe REST 原生 Token）。
