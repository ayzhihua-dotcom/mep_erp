## 二、功能设计

### 2.1 交期管理（PUR-008）

| 字段（PO 行级或行检索扩展） | 规则 |
| --- | --- |
| original_schedule_date（原计划） | 下单时快照；改单后不覆盖 |
| latest_promised_date（最新承诺） | 供应商确认承诺日期；可多次更新，更新留痕 |
| actual_delivery_date（实际交货） | 取首张部分收货 Purchase Receipt 日期 |
| promise_history（承诺记录子表） | 每次承诺更新：日期、承诺数值、来源（邮件/电话+操作人） |

联动：承诺日期晚于 MR 需求日期 → 触发 ALR-002（占位，正式预警在 S5）；供应商逾期未交（承诺日已过无收货）→ ALR-002。

### 2.2 订单关闭（PUR-009）

| 校验项 | 规则 |
| --- | --- |
| 剩余未交数量 | 行累计已收/已发运量统计；未交量 > 0 须选择处理方式：关闭剩余 / 转退货说明 |
| 绑定退货 | 存在未结退货单据时阻断或提示 |
| 挂起费用 | 检查未结算发票占位记录 |
| 异常事项 | 未关闭的订单级异常须标注或结转 |
| 关闭动作 | `custom_close_reason`（正常/缺交关闭/协商取消/项目取消）+ 审批（> 档位金额走 PUR-006 阈值同款二级）；关闭后只读 |

### 2.3 供应商绩效（PUR-010，P1）

| 指标 | 数据来源 |
| --- | --- |
| 准时交付率 | 实际交货日期 vs 最新承诺日期（PUR-008） |
| 订单完成率 | 关闭原因分布 + 未交量占比 |
| 质量异常次数 | 关联 INV 检验不合格记录数（S3 后可算，先开发字段与口径） |
| 价格变化率 | 同 Item 同供应商跨订单单价变动 |
| 输出 | 供应商绩效看板（按季度/项目）；供 LPO-007 对比接口复用 |
