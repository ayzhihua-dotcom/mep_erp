## 三、配套约定

1. 全部定制 fieldname 统一以 `custom_` 前缀（fixtures 命名空间隔离）；
2. 必填/校验规则用 server script + fixture 双份登记（校验逻辑不散落）；
3. 本表为字段级"登记册"：开发实建后若 fieldname/类型有调整，以实建为准回填本表并变更记录；
4. 枚举字典统一在第二节各 Select 项，字典值冻结走《业务决策总表》对应条目。
