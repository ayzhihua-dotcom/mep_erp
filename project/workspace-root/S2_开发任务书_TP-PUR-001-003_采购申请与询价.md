## 二、标准对象复用与定制点

### 2.1 Material Request（PUR-001）

| 项 | 方案 |
| --- | --- |
| 复用范围 | 标准 MR：`purpose`（建议材质类：Purchase）、company、transaction_date、required_by、items 子表 |
| 定制字段 | `custom_project`（行级已有 project 字段，补充主表展示）；`custom_demand_source`（来源：Design BOM 版本/行引用）；设置 `set_warehouse` → 目的仓规则（按项目现场仓） |
| 来源追溯 | 行级 `source_bom_docname / source_bom_item`（承接 Design BOM 行）→ 支撑 PRJ-006 需求汇总（TP-PRJ-004）取数口径 |
| 拆分规则 | 一个 MR 行可拆到多个询价/订单（标准支持）；拆分后行剩余量状态由系统维护 |
| 提交后锁定 | 标准 submit 行为即锁定；改单走取消/修订（V0.2 通用原则） |

### 2.2 Request for Quotation（PUR-003）

| 项 | 方案 |
| --- | --- |
| 复用范围 | 标准 RFQ：供应商列表子表、`transaction_date`、`message_for_supplier`、items |
| 定制点 | ① 截止日期与发出时间记录（`custom_footer_deadline`）；② 币种（`custom_currency_scope`，与采购公司币种一致，中国 CNY / 巴西 BRL）；③ 付款/交货条件文本模板（Print Format 承载，含双语模板见 S1 ③）；④ 仅允许向"激活且对应分组"的供应商发出（MDM 分组 + PRC/BRA 角色范围联动） |
| 输出 | 供应商联系方式与邮件发送走标准 Sender 功能；发出时间自动记录 |

### 2.3 Supplier Quotation（PUR-005 商务比价承载）

| 项 | 方案 |
| --- | --- |
| 复用范围 | 标准 SQ：supplier、rate、valid_till、items 关联 RFQ/MR 行 |
| 定制字段 | ① `custom_tax_inclusive`（含税/未税口径标志，BRA 端常含税、PRC 端按发票口径——口径名待业务确认）；② `custom_moq` / `custom_lead_time`（最小起订/交期）；③ `custom_payment_terms_text`；④ 运费/包装说明文本 |
| 比价视图 | 比价单据清单报表（一行 MR 行 × 多家 SQ 对照：单价、币种、含税口径、交期、有效期）；过期报价自动标记"已过期"并可设过滤（有效期告警接 ALR-002 同一机制） |
| 行关联 | 报价行必须关联 to MR / RFQ 行（标准 rfq 链保留；定制校验防止孤立报价） |

## 三、接口约定（对上下游）

| 接口点 | 约定 |
| --- | --- |
| → PUR-004 技术审核 | SQ/RFQ 供 PUR-004 检查"材料规格/品牌/替代材料批准情况"；本任务保证报价行的 item/规格来源一致（不完整实现，仅字段与状态开放给审核流） |
| → TP-PUR-006/007 | MR 提交状态与 SQ 被选用记录作为订单创建输入；"被选用"动作（win quotation）走标准功能，选用记录作为订单行追溯源 |
| ↢ PUR-002 / PRJ-006 | 本任务提供行级"已申请/已下单量"统计字段（标准 status + 里程），供需求计算取数，不承担计算 |
| ↢ 预算 | MR 行预留 `custom_budget_check`（预算校验结果回写字段），校验逻辑属 TP-CST-001/002，本任务仅预留接口位 |

## 四、状态机（联合流）

| 单据 | 状态流 |
| --- | --- |
| Material Request | 草稿 → 已提交（锁定）→（可选比价）→（进入 PUR-006 审批）→ 已批准 → 订单化/关闭 |
| RFQ | 草稿 → 已发出（记录发出时间；可选二级：待人询单关闭）→ 已收回应并入 SQ / 以"关闭"结案 |
| Supplier Quotation | 草稿 → 已提交（有效报价）→ 过期/被选用/落选退出 |
