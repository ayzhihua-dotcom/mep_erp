- 编制依据：V0.2 字段字典（CST-004 进口分摊 / CST-003 实际费用）、ERPNext Landed Cost Voucher 能力、TP-LOGIMP-002（Import Cost 就绪）、《S2 开发任务书：需求汇总与成本核算》。
- 编制日期：2026-10-28
- 状态：草稿

## 一、任务定位

| 项 | 内容 |
| --- | --- |
| 覆盖功能 | CST-004（P1）：进口费用分摊至材料 → 库存/项目成本的完整链路（IMP-009 成本关联正式闭环） |
| 实现形态 | ERPNext Landed Cost Voucher（标准）+ Import Cost → LCV 通道 + 分摊方案定制 |

## 二、功能设计

### 2.1 通道

| 链路 | 规则 |
| --- | --- |
| Import Cost → LCV | 案件费用（已审批实付）生成 LCV 候选清单 → 选用生成 LCV（对接收货单据 Purchase Receipt / Stock Entry） → 分摊至行 Item |
| 分摊基础 | 按金额占比（货值）/ 数量 / 毛重 / 体积，四选一默认（每种 Import Cost 可指定） |
| 结果 | 分摊后 Item 单价（含税成本）进入库存与项目成本（BRA 端成本报表主口径） |

### 2.2 项目维度

- 收货/入库行带回项目归属（Project Allocation 链）→ 分摊成本逐归到项目实际费用（CST-003 完整化）；
- 案件覆盖多项目时按收货行分配比例拆分。

### 2.3 核对与审计

| 规则 |
| --- |
| 分摊结果回写 Import Cost `allocated_amount`；未分摊差额提示（舍入差额定向在首尾行平衡） |
| 分摊方案与计算过程可回查（LCV + Allocation 明细保存） |
| 分摊调整须走过审批 + Cost Audit Log（CST-008） |
