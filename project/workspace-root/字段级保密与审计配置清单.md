## 一、字段级保密矩阵

图例：F=可见可编辑 / V=可见只读 / H=隐藏 / −=单据本身不可见（随数据范围已隔离，不重复列）。

### 1.3 内控校验字段（只能系统回写，人工一律只读）

| 字段 | 规则 |
| --- | --- |
| custom_budget_check（超限金额） | 系统计算回写；全角色只读，SYS 除外 |
| custom_approval_threshold | 系统按金额分档回写 |
| Shipment Item shipped_qty（发运累计） | 系统累计；whs 只读 |

### 1.4 实现机制（v16）

- 表单字段隐藏：Customize Form → depends_on / read_only / hidden + 角色差异用 Client Script 或 Field Permission 扩展（如需字段级角色差异，v16 原生不含 field-level RBAC，须用定制 —— 记为开发项 SEC-01：字段保密用"表单渲染过滤 + 报表列过滤"双重实现，服务端 API 同步过滤防绕过）；
- 报表保密：报表按 Role 授权列表控制 + 列级过滤常量；
- API 防绕过：服务端 `has_permission` 检查按字段计算（定制成承层）。

## 二、审计事件配置清单（ALR-006 / CST-008 落地层）

### 2.1 强制 track_changes（版本历史开启）的 DocType

Design BOM / Change Request / PO / Shipment / Import Case / Import Cost / Material Budget / Stock Entry（领料/调拨/盘点）/ Supplier / Item（custom 字段变更）/ Alert Event 处理记录。

### 2.2 六类必审计事件及承载

| 事件 | 承载 | 补充要求 |
| --- | --- | --- |
| 提交/审批 | Workflow 状态历史 + Version | 审批意见必填 |
| 汇率覆盖 | Conversion Rate 修改记录 + Cost Audit Log | 原/新值+原因 |
| 数量更改（已批准单据） | Version + 改单原因字段 | 重新审批链 |
| 成本分摊（LCV） | LCV + Allocation 版本 + Cost Audit Log | 分摊基础变更须审批 |
| 主数据合并停用 | Item/Supplier disabled + track_changes | 合并映射记录 |
| 状态豁免（例外通道） | 事件入 ALR 队列 + Cost Audit Log | 豁免权限角色清单固化 |

### 2.3 Cost Audit Log（统一审计单）

| fieldname | 说明 |
| --- | --- |
| audit_type / ref_doctype / ref_docname | 事件类型/对象 |
| old_value / new_value / reason | 原值/新值/原因（必填） |
| operated_by / approved_by / approved_ok | 操作人/审批人（豁免类须 approval） |
