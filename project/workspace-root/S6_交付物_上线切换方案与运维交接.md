## 一、上线切换方案

### 1.1 切换策略（建议并行缓冲期）

| 策略 | 描述 |
| --- | --- |
| 主策略：分批切换（模块分批上线接 SRS 阶段计划：S1~S5 模块化上线） | 每模块上线带 30~60 天并行旧方式校验期（纸质/表格 → 系统为准） |
| 数据初始化 | 主数据全量（S1 ④ 规范 Prod 版）+ 期初库存盘点导入（INV-009 规程）+ 期初未结单据（在途 PO/案件）登记为"期初快照单" |
| 切换日操作清单 | 备份全量 → 数据导入核对清单 → 双人核对（业务方+SYS）→ 启用告警观测窗口 |

### 1.2 上线观测期

- 上线后 2 周：每日日报（登录数、关键单据创建量、预警触发与处置率、缺陷反馈）；
- 观测期结束条件：连续 5 天无高危缺陷 + 业务关键流程全部在系统执行。

### 1.3 回退预案

- 重大故障：恢复最近备份（细案 RTO 路径）+ 声明回退窗口与数据处理边界（切换日以来新增数据的处理：暂停录入 → 回退 → 补录）。

## 二、运维交接

| 事项 | 移交内容 |
| --- | --- |
| 系统管理 | SYS 操作手册（用户/权限/Workflow 维护）、变更流程 |
| 版本升级 | 升级 runbook（小版本窗口、升级前备份与回退、测试环境先验证） |
| 备份与演练 | Prod 备份作业配置、演练日程表与记录格式 |
| 与开发方协作 | 缺陷/需求变更工单机制、SLA 与维护期约定（合同细节由商务侧另议） |

## 三、验收要点

1. 切换 runbook、观测日报模板、回退预案三件齐备并评审。
2. 期初数据双人核对记录留档。
3. 运维交接清单双方签字。
