# 《S4 交付物：生产环境部署形态终案》草案（V0.1）

- 编制依据：SRS §部署安全、《S1 交付物：环境搭建与定制应用骨架方案》（O-01 承接）、S4 阶段定位。
- 编制日期：2026-10-28
- 状态：草稿（需业务方决策 O-01 后定稿）

## 一、决策框架（O-01）

| 选项 | 优势 | 代价 | 评估倾向（待业务/技术主题评审） |
| --- | --- | --- | --- |
| A. Frappe Cloud（官方托管） | 运维最轻、备份/升级官方处理 | 数据出境/合规需评估；费用订阅 | 简单优先倾向，合规评估关键 |
| B. 云主机自托管（AWS/阿里/本地 IDC IDC 由于巴西区域） | 数据可控、巴西区低延啶 | 需运维力量；备份/升级自理 | ERPNext 用户主模式 |
| C. 本地独立服务器机房 | 数据完全本地 | 硬件/冷却/灾备负担 | 巴西现场办公场景可能倾向 |

> 评估要素：巴西数据合规（LNPD/GDPR 边界）、IT 运维力量、预算、灾备 SLA；三项中任一冻结即更新本方案终稿。

## 二、生产环境架构草案（以自托管为主线预设）

| 层 | 方案 |
| --- | --- |
| 应用 | frappe-docker Compose：App / MariaDB / Redis (Cache, Queue, SocketIO) / Nginx |
| 容量 | 起步 2 vCPU/8GB 单机可承载 10~30 并发（业务量确认后调优，容量假单文件） |
| 域名/HTTPS | 约定域名（O-02 承接）+ Let's Encrypt 证书 |
| 访问 | 内网/VPN 访问网管网管；移动端按 D-11 需求出外网可达（边界由防火墙策略给） |
| 备份 | 按《备份与恢复细案》Prod 部分：每日全量+日志，备份外置独立存储 |
| 升级通道 | 半年一次核验版本小版本升级窗口（对应 L-02 版本策略） |

## 三、迁移与启用路径

1. Dev/Test 配置（站点）迁移：Data Import 模板 + fixtures + Git 代码；
2. 主数据初始化（按 S1 ④，Prod 环境同一规范执行，替换 D-8 示例用户为真实账号与 P-01 名单）；
3. UAT 通过后 Prod 上线（衔接 S6 上线切换方案）；末转出运行基线到备份储藏。

## 四、验收要点

1. O-01 三选一冻结并记录决策理由。
2. 依据选择形成部署 runbook（脚本/步骤/回退路径）。
3. Prod 环境安全基线（强口令/最小权限/审计日志开启）确认，纳入 S6 验收。
