# 出入库管理系统 - 桌面版

一个简单易用的桌面出入库管理软件，使用Python tkinter开发。

## 功能特性

- 🔐 用户登录认证
- 📊 仪表盘 - 查看库存概览
- 📦 商品管理 - 增删改查商品信息
- 📥 入库管理 - 记录商品入库
- 📤 出库管理 - 记录商品出库
- 🔍 库存查询 - 搜索和查看库存
- 📋 库存盘点 - 定期盘点调整
- ↩️ 退入库 - 处理退货退库
- 📊 报表统计 - 出入库统计分析
- 👥 用户管理 - 管理系统用户

## 运行方式

```bash
cd inventory_desktop
python main.py
```

## 默认账户

- 用户名：admin
- 密码：admin123

## 系统要求

- Python 3.x
- 无需安装额外依赖（使用Python内置tkinter）

## 界面说明

- 左侧导航栏：点击不同模块进行切换
- 顶部菜单：文件 -> 退出登录/退出系统
- 所有数据存储在 inventory.db 数据库文件中

## 注意事项

- 首次运行会自动创建数据库和默认管理员账户
- 库存不足时会以红色显示预警
- 管理员可以管理其他用户账户
